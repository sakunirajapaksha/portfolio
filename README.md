# Sakuni Portfolio 🚀

A modern, responsive full-stack developer portfolio showcasing projects, skills, and experience with a sleek dark theme interface.

**Live Demo:** [portfolio-flax-one-44.vercel.app](https://portfolio-flax-one-44.vercel.app)

---

## 🛠️ Tech Stack

- **Frontend:** Next.js 13+, React, Tailwind CSS
- **Backend:** Node.js
- **Styling:** Tailwind CSS with dark mode
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

---

## ✨ Features

- 🎨 **Modern UI Design** - Clean and professional interface
- 🌙 **Dark Theme** - Easy on the eyes with smooth theme switching
- 📱 **Fully Responsive** - Works seamlessly on all devices
- ✉️ **Contact Form** - Get in touch functionality
- ⚡ **Fast Performance** - Optimized with Next.js
- 🎯 **Project Showcase** - Display your best work
- 💼 **Skills Section** - Highlight your technical expertise
- 📊 **About Me** - Tell your story

## 🚀 Getting Started

### Prerequisites
- Node.js 14+ 
- npm or yarn

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/sakunirajapaksha/portfolio.git
cd portfolio
```

2. **Install dependencies:**
```bash
npm install
# or
yarn install
```

3. **Run the development server:**
```bash
npm run dev
# or
yarn dev
```

4. **Open your browser:**
Navigate to [http://localhost:3000](http://localhost:3000)

## 📝 Usage

Customize the portfolio with your information:

1. Update personal details in relevant component files
2. Add your projects to the projects section
3. Update skills and experience
4. Modify colors and styles in Tailwind CSS configuration

---

## 📧 Contact Form

The portfolio includes a contact form to receive messages. Make sure to configure your backend endpoint for form submissions.

---

## 🎨 Customization

### Theme Colors
Modify the Tailwind CSS configuration in `tailwind.config.js` to change colors and theme settings.

### Dark Mode
Dark mode is enabled by default with the ability to toggle between light and dark themes.

---

## 🚢 Deployment

The portfolio is deployed on **Vercel** and automatically deploys from the main branch.

To deploy your own version:
1. Push your code to GitHub
2. Connect your repository to Vercel
3. Vercel will automatically build and deploy
